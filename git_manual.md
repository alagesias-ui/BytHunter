Po každé změně kódu zadat:



1. ***ctrl + s*** pro uložení
2. ***git add .*** – připraví všechny změněné soubory ve složce ke uložení (tečka znamená „všechno ve složce“).
3. ***git commit -m "komentář ke změně"*** – vytvoří lokální uložení (snapshot) s tvou zprávou (např. git commit -m "úprava extract skriptu").
4. ***git push*** – pošle tvoje lokální změny nahoru na webový GitHub.



Pro získání aktuálního kódu z GITu

**git pull**
